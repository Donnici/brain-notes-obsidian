# Brain Notes for Obsidian

Release builds of the Brain Notes plugin for Obsidian (iOS, Android and desktop, Obsidian 1.11.4 or newer).
The source lives in a private repository; this one only holds what BRAT installs.

## Install

1. Install the **BRAT** community plugin in Obsidian.
2. BRAT → "Add beta plugin" → `Donnici/brain-notes-obsidian`.
3. Enable **Brain Notes**, open an empty vault and choose "Conectar ao GitHub".
